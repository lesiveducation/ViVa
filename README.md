# ViVo

Публичная страница бизнес-брифа с анкетой, встроенной из Яндекс Форм.

## Локальный запуск

1. Установить зависимости: npm install
2. Запустить сайт: npm run dev
3. Открыть адрес, показанный в терминале.

## Публикация

GitHub Actions автоматически собирает и публикует сайт в GitHub Pages после отправки изменений в ветку main.

Адрес сайта: https://lesiveducation.github.io/ViVo/

## Ключ GitHub

Ключ не должен храниться в проекте, файлах .env или настройках сайта. Для публикации Pages используется автоматически создаваемый GitHub секрет GITHUB_TOKEN.

Для первой отправки проекта авторизуйтесь через Git Credential Manager. Если GitHub запросит Personal Access Token, вводите его только в системное окно авторизации Git, в поле пароля. Не вставляйте токен в файлы проекта и не отправляйте его в чат.
