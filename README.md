# ViVa

Многостраничный сайт бренда авторских украшений ViVA: витрина коллекции, индивидуальные заказы, сертификаты, журнал и контакты мастерской.

## Локальный запуск

1. Установить зависимости: npm install
2. Запустить сайт: npm run dev
3. Открыть адрес, показанный в терминале.

## Публикация

GitHub Actions автоматически собирает и публикует сайт в GitHub Pages после отправки изменений в ветку main.

Адрес сайта: https://lesiveducation.github.io/ViVa/

## Контент

Товары хранятся в `src/data/products.js`, статьи — в `src/content/blog/`. Сборка и публикация выполняются автоматически через GitHub Actions.
